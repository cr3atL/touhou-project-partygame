# 幻想乡巡游

东方角色主题的四人飞行棋，七名角色各有一个主动和被动技能。支持同机游玩、单人式神对局和在线四人房间。

[打开游戏](https://cr3atl.github.io/touhou-project-partygame/) · [下载与更新记录](https://github.com/cr3atL/touhou-project-partygame/releases)

当前版本 **v0.1.5**（2026-10-26）。游戏仍在持续调整，欢迎通过 Issue 反馈玩法和平衡问题。

## 开始游玩

- **同机游玩**：四位玩家轮流操作，也可将部分席位交给式神。
- **单人游玩**：选择“单人游玩 · 三名式神同行”。
- **四人房间**：创建房间并分享房间号，其他玩家输入房间号加入。选角和准备完成后，由房主开始；空位可用式神补齐。
- **基本操作**：掷骰后点击发光棋子。有多个结果时，再选棋子或落点；施放符卡时选择目标并确认。棋盘支持拖动、缩放和手机双指操作。

设置可以调整音效、音量、地图特效和镜头特写，并可回到大厅。本地和单人模式打开设置自动暂停，关闭后继续；联机模式不会因此暂停其他玩家。巡游记录收起时显示最近记录，展开可按回合查看。

## 对局规则

每人控制四枚棋子，四枚全部完成后按顺序获得名次并退出行动。决出前三名后整局结束，剩余玩家为第四名。

- 任意骰点均可出场，消耗该次行动，先停在独立出场格；下一次骰子行动再进入主路。出场不撞击或触发加速。
- 落在己方颜色时自动跳格；抵达专属航线入口自动飞行，飞行结束后可再跳一次。普通途经格不撞击，航线可以撞击所经过的终点道交叉格。
- 同一撞击位置的全部敌棋先处理保护，再按实际撞毁数结算；撞毁两枚及以上时同归于尽，进攻棋子的保护可以抵消返航。航线交叉格与最终落点分别计数。
- 终点必须精确到达，步数超过时先到终点再折返。
- 自然六点追加行动，不刷新回合时间或技能次数；连续第三个自然六点取消行动，让上一次骰子行动移动的棋子返航并结束回合。保护可以抵消返航，已完成的棋子不受影响。
- 每回合共用 **60 秒**决策时间，不可操作的演出期间暂停扣时。最后 5 秒播放倒计时音效；超时后式神完成本回合，下回合恢复玩家控制。

角色技能和冷却可在主页及对局符卡面板查看。技能额外位移不撞击、不触发跳格或航线，也不能直接进入终点道。

- 传统十字棋盘、四色厚六边形地砖、切分转角及独立出场格；旧地区地图和冥界分支下架。

- 服务器权威计时、单回合超时托管；刷新或重连不会重置剩余时间。
- PC 与手机统一深色背景；手机使用全宽棋盘和底部操作区，放大地砖、棋子及可选落点。
- 设置精简，新增回到大厅；正式构建排除场景生成器、模拟对局及调试入口。

本地对局自动保存，可从“继续上次”恢复。新棋盘与旧地图存档不兼容，导入旧存档会提示版本不兼容，原文件不会被覆盖。

## 在线房间

房间服务部署在 Render。免费实例休眠后，首次连接可能等待约一分钟。异常断线保留席位 120 秒；主动离开或超过重连时间后由式神接管。服务重启或重新部署后，内存中的房间不会保留。

网页与房间服务需要使用匹配的规则和协议版本。升级期间若提示版本不兼容，请等待房间服务更新后刷新网页。

## 本地开发与验证

需要 Node.js 22 或更新版本，建议使用 24。

```sh
npm ci
npm run dev
```

打开 `http://localhost:5173`。启动时会显示局域网地址。

```sh
npm test
npm run build:server
npm run test:rooms
npm run test:network
npm run test:decision-network
npm run test:room-management
npm run build
npm run check:release
```

`node scripts/generate-board.mjs` 从同一组坐标生成地图数据及桌面、手机两套 SVG。测试场景和模拟工具仅位于 `tests/helpers/`，不提供网页或房间调用入口。

## 部署

推送 `main` 后，GitHub Actions 会运行测试、构建与发布检查，再部署 GitHub Pages。网页使用仓库变量 `VITE_ROOM_SERVER_URL` 指定公开的 `wss://` 房间地址，构建时自动适配仓库子路径。

Render 使用仓库中的 `render.yaml` 构建房间服务，检查通过后自动部署。手动运行 `npm run build:server` 后可用 `npm start` 启动服务；`GET /health` 返回健康、规则与协议版本，不提供调试或改写状态接口。

东方 Project 相关角色属于原作者。音效素材来源见 [public/audio/sources.json](public/audio/sources.json)。
