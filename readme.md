# 幻想乡巡游

以东方角色为主题的四人派对棋。掷骰前行、施放符卡，在幻想乡的地面与冥界路线之间展开竞赛，七名角色各有不同的主动和被动技能。

[打开游戏](https://cr3atl.github.io/touhou-project-partygame/)

## 开始游玩

- **同机游玩**：四名玩家轮流操作，也可选择“一人试玩”，与三名式神对局。
- **四人房间**：创建房间并分享房间号，朋友输入房间号加入。选好角色并准备后，由房主开始；空位可用式神补齐。
- **基本操作**：掷骰后点击发光棋子；有多个落点时，再选择目标格。施放符卡时按提示选棋、选目标并确认。

每人控制四枚棋子，全部进入终点后获得名次并退出行动。决出前三名后整局结束，剩余玩家列第四名。主页可查看所有角色的技能介绍。

联机使用独立的 Render 房间服务，无需手动填写地址。免费服务休眠后，首次连接可能等待约一分钟；异常断线可在120秒内重新连接。服务重启或重新部署后，当局房间不会保留。

## 本地运行

需要 Node.js 22 或更新版本，建议使用24。

```sh
npm ci
npm run dev
```

打开 http://localhost:5173 。启动时也会显示局域网地址，同一网络的朋友可通过该地址游玩。

## 构建与部署

`npm run build` 构建网页，`npm run build:server` 构建房间服务，`npm start` 启动房间服务。`npm test` 运行规则与界面逻辑测试。

网页通过 GitHub Pages 自动发布，房间服务使用仓库中的 `render.yaml` 配置部署。两者独立运行。
